# Hotel Booking Cancellation Predictor

## Project Description
This project predicts whether a hotel booking is likely to be cancelled using Machine Learning.

## Algorithm
Random Forest Classification.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Dataset
Hotel Booking Demand Dataset.

The dataset is downloaded automatically from a public GitHub repository.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

Open the Streamlit URL in your browser.

## Deployment
Deploy this project using Streamlit Community Cloud by connecting your GitHub repository.

## Output
The application displays cancellation probability and predicts whether a booking is likely to be cancelled.
